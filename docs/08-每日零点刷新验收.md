# 每日零点刷新

## 运行行为

开机读取 PCF8563 的本地时间，绘制当天年月日、农历、星期、节气和全部节日。班次名称与两个时段保持空白，保留页面分隔线和“今日班次”标签。

完成刷屏后设置下一天 00:00 的 RTC ALARM，以 GPIO5 低电平作为 ESP32-S3 EXT1 唤醒源。GPIO17 保持电池供电，关闭屏幕和其他不使用的外设，再进入 deep sleep。闹钟唤醒后重复执行，不限制累计唤醒次数。此流程无需 WiFi 或电脑。

刷屏或设置闹钟期间跨过零点时，立即绘制新日期。RTC 读取失败、VL 标志置位或日期非法时明确报错，禁止使用固定日期替代真实时间。

## 设备校时与复测

`CALENDAR_RTC_CONSOLE=ON` 仅用于设备校时和真实闹钟验证。该构建通过 USB 接收 JSON 命令，直接设置真实 PCF8563 时间，然后执行每日刷新代码。正式交付固件使用 `CALENDAR_RTC_CONSOLE=OFF`。

```powershell
tools/.venv/Scripts/python.exe tools/idf.py -C app -DCALENDAR_RTC_CONSOLE=ON build
tools/.venv/Scripts/python.exe tools/flash_retry.py --port COM5 --baud 921600
tools/.venv/Scripts/python.exe tools/calendar_device.py test --seconds 180
tools/.venv/Scripts/python.exe tools/calendar_device.py sync
tools/.venv/Scripts/python.exe tools/idf.py -C app -DCALENDAR_RTC_CONSOLE=OFF build
tools/.venv/Scripts/python.exe tools/flash_retry.py --port COM5 --baud 921600
```

实测使用 RTC 的真实日期跨越中秋节、月底和年末，并核对 GPIO5 唤醒原因、当天页面及下一天闹钟。测试结束必须恢复当前北京时间，并烧录关闭校时验证入口的正式固件。原始日志按时间命名并保存在项目的 `.tmp_device/`。
