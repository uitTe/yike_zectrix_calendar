# 云函数中转调用权限设计文档

## 1. 架构概述

第三方系统通过 AGC OAuth 接口获取鉴权 Token，携带 Token 调用中转云函数，中转云函数校验 Token 及环境变量后，通过 Server SDK 调用目标业务云函数。

```mermaid
flowchart TD
    A[第三方系统] -->|1. clientId + clientSecret 获取Token| B[AGC OAuth接口]
    B -->|2. 返回 access_token| A
    A -->|3. 携带Token + 业务参数<br/>POST 触发URL| C[中转云函数<br/>authType: apigw-client]
    C -->|4. 校验Token有效性| C
    C -->|5. 校验环境变量<br/>如API_KEY、白名单等| C
    C -->|6. 校验通过<br/>Server SDK自动鉴权调用| D[目标业务云函数<br/>authType: cloudgw-client]
    C -->|7. 校验失败<br/>返回401/403| A
    D -->|8. 执行业务逻辑<br/>返回结果| C
    C -->|9. 返回业务结果| A
2. 角色与职责定义
角色	职责	鉴权方式
第三方系统	发起业务请求的 external caller	持有 clientId / clientSecret，获取 AGC Token
中转云函数	校验入口、参数转发、权限控制	HTTP 触发器 authType: apigw-client，需第三方携带 Token 调用
目标业务云函数	执行实际业务逻辑	HTTP 触发器 authType: cloudgw-client，仅允许云侧调用

4.2 环境变量配置
在 AGC 控制台 → 云函数 → 中转函数 → 配置 → 环境变量中设置：

变量名	说明	示例值
TARGET_FUNCTION_NAME	目标业务云函数名称	query-schedules-range
TARGET_FUNCTION_VERSION	目标函数版本	$latest
ALLOWED_CLIENT_IDS	允许的第三方 clientId 白名单，逗号分隔	client_001,client_002
CUSTOM_API_KEY	第三方自定义 API Key，用于二次校验	your-custom-secret-key
4.3 中转函数代码示例
// 文件：proxy-function.ts
import { cloud } from "@hw-agconnect/cloud-server";

let myHandler = async function (event, context, callback, logger) {
  try {
    // ========== 第一步：解析请求参数 ==========
    let body = event.body ? JSON.parse(event.body) : event;

    // ========== 第二步：校验自定义 API Key ==========
    let customApiKey = process.env.CUSTOM_API_KEY;
    if (!customApiKey || body.apiKey !== customApiKey) {
      logger.warn("自定义API Key校验失败");
      callback({ code: 401, message: "unauthorized: invalid api key" });
      return;
    }

    // ========== 第三步：校验 clientId 白名单 ==========
    let allowedClientIds = (process.env.ALLOWED_CLIENT_IDS || "").split(",");
    let clientId = event.headers && event.headers["client_id"];
    if (!clientId || !allowedClientIds.includes(clientId)) {
      logger.warn("clientId不在白名单中: " + clientId);
      callback({ code: 403, message: "forbidden: client not allowed" });
      return;
    }

    // ========== 第四步：校验业务参数 ==========
    if (!body.data || !body.data.dateRange) {
      callback({ code: 400, message: "bad request: missing dateRange" });
      return;
    }

    // ========== 第五步：调用目标云函数 ==========
    let targetName = process.env.TARGET_FUNCTION_NAME;
    let targetVersion = process.env.TARGET_FUNCTION_VERSION || "$latest";

    logger.info("开始调用目标函数: " + targetName);

    const result = await cloud.function().call({
      name: targetName,
      version: targetVersion,
      data: body.data  // 仅透传业务数据，不透传鉴权信息
    });

    logger.info("目标函数调用成功");
    callback(result);

  } catch (error) {
    logger.error("中转函数异常: " + JSON.stringify(error));
    callback({ code: 500, message: "internal error" });
  }
};

export { myHandler };

5.3 第三方代码示例（Node.js）
const axios = require('axios');

// 配置
const config = {
  clientId: 'your-client-id',
  clientSecret: 'your-client-secret',
  customApiKey: 'your-custom-secret-key',
  tokenUrl: 'https://connect-drcn.dbankcloud.cn/agc/apigw/oauth2/v1/token',
  proxyFunctionUrl: 'https://your-agc-gateway/functions/your-project-id/proxy-function-$latest'
};

// 第一步：获取 Token
async function getToken() {
  const res = await axios.post(config.tokenUrl, {
    grant_type: 'client_credentials',
    client_id: config.clientId,
    client_secret: config.clientSecret,
    useJwt: 1
  });
  return res.data.access_token;
}

// 第二步：调用中转云函数
async function callCloudFunction(businessData) {
  const token = await getToken();
  const res = await axios.post(config.proxyFunctionUrl, {
    apiKey: config.customApiKey,
    data: businessData
  }, {
    headers: {
      'Authorization': 'Bearer ' + token,
      'Content-Type': 'application/json'
    }
  });
  return res.data;
}

// 使用示例
callCloudFunction({ dateRange: '2026-09-01~2026-09-30' })
  .then(result => console.log('结果:', result))
  .catch(err => console.error('错误:', err.response?.data || err.message));

7. 部署步骤
7.1 部署目标业务云函数
在 DevEco Studio 中创建云函数 query-schedules-range
配置 function-config.json，authType 设为 cloudgw-client
右键函数目录 → Deploy Function
在 AGC 控制台确认触发器认证类型为"API客户端鉴权（server适用）"
7.2 部署中转云函数
在 DevEco Studio 中创建云函数 proxy-function
配置 function-config.json，authType 设为 apigw-client
在 package.json 中添加 @hw-agconnect/cloud-server 依赖
右键函数目录 → Deploy Function
在 AGC 控制台配置环境变量（见 4.2 节）
在 AGC 控制台确认触发器认证类型为"API客户端鉴权（client适用）"
7.3 部署验证
验证项	方法	预期结果
目标函数拒绝端侧直接调用	携带 Token 直接调用目标函数触发 URL	返回鉴权失败
中转函数拒绝无 Token 调用	不带 Authorization 头调用中转函数	返回 401
中转函数拒绝错误 API Key	携带正确 Token + 错误 apiKey 调用	返回 401 invalid api key
中转函数拒绝非白名单 clientId	携带正确 Token + 非白名单 clientId 调用	返回 403 forbidden
正常调用链路通	携带正确 Token + 正确 apiKey + 白名单 clientId 调用	返回业务结果
8. 安全注意事项
事项	说明
Token 缓存与刷新	Token 有过期时间（通常 3600 秒），第三方应缓存 Token 并在过期前刷新，避免每次请求都获取新 Token
环境变量管理	CUSTOM_API_KEY 和 ALLOWED_CLIENT_IDS 通过 AGC 控制台环境变量配置，不要硬编码在代码中
日志脱敏	中转函数日志中不要打印完整的 Token、API Key 等敏感信息
目标函数隔离	目标函数 authType 必须为 cloudgw-client，确保无法被端侧直接调用
最小权限原则	clientId 白名单仅包含实际需要调用的第三方，定期清理
HTTPS 强制	所有调用必须通过 HTTPS，AGC 网关默认强制 HTTPS
